# DevSecOps_CiCd

![CI](https://github.com/DiegoNunesSilva/DevSecOps_CiCd/actions/workflows/ci.yml/badge.svg)

Este repositório contém exemplos de pipelines de CI/CD usando GitHub Actions.

## 🚀 Objetivo
Demonstrar como configurar workflows básicos e evoluir para testes automatizados e práticas de DevSecOps.

## 📂 Estrutura
- `.github/workflows/ci.yml` → Pipeline de integração contínua
- `README.md` → Documentação inicial

## ▶️ Como usar
1. Faça um commit e push para o repositório.
2. O GitHub Actions executará automaticamente o pipeline definido em `ci.yml`.
3. Confira os resultados na aba **Actions** do GitHub.
